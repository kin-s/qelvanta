# QELVANTA

**Work smarter. Grow faster.** — Your business. One platform.

Premium international business management SaaS. Frontend-first build; backend integration deferred to a later phase.

## Stack
- Next.js 16 (App Router) · React 19 · TypeScript
- Tailwind CSS v4
- Lucide icons · Framer Motion · Recharts
- React Hook Form + Zod
- next-themes (theme persistence)
